    谈判背景

    写得越具体，提醒越准。这些内容只保存在这台手机上，只在分析时发给 Claude。

    设置

    API Key 只保存在这台手机的浏览器里，直接发给 Anthropic，不经过任何其他服务器。

    使用提示
    • 用 Safari 直接打开这个网址，不要从主屏幕图标、微信或其他 App 里打开，否则可能无法收音。
    • 手机放在桌上靠近对方的一侧，收音效果最好；锁屏会中断收音，页面会尽量保持屏幕常亮。
    • 转写不区分说话人，AI 会根据内容推断谁在说。关键数字听错时，用底部「手动补充」纠正。
    • 建议给这个 Key 在 Anthropic 控制台单独设置用量上限。
